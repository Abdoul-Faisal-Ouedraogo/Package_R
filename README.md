# ldapkg: predictive linear discriminant analysis for R

[![R-CMD-check](https://github.com/Abdoul-Faisal-Ouedraogo/ldapkg/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/Abdoul-Faisal-Ouedraogo/ldapkg/actions/workflows/R-CMD-check.yaml)

`ldapkg` implements **predictive linear discriminant analysis (LDA)** in an
[R6](https://r6.r-lib.org/) class whose interface follows scikit-learn
(`fit()`, `predict()`, `predict_proba()`), together with the statistics needed
to interpret the model and a Shiny application.

* **Efficient core**: one pass over the data (`rowsum()` + `crossprod()`), then
  Cholesky factorisations on `p x p` matrices; standardised internally, so
  variables measured in very different units are no problem.
* **Any number of classes** (K >= 2), empirical / equal / user priors.
* **Interpretation**: classification functions, posterior probabilities,
  Wilks' lambda + Rao's F, partial Wilks' lambda / F / tolerance of each
  variable, canonical discriminant axes, confusion matrix, per-class metrics,
  cross-validation.
* **Categorical predictors**: dummy coding handled transparently (the encoding
  is stored and re-applied at prediction time); a categorical variable is
  tested and selected **as a block**.
* **Variable selection**: forward, backward and stepwise (Wilks' lambda,
  Rao's F), computed from the `E` and `T` matrices only (no re-reading of the data).
* **Robust**: constant / collinear columns are dropped with a warning, missing
  values are handled, unseen factor levels give `NA` instead of an error.
* **Shiny application**: `ldapkg::run_app()`.

## Installation

```r
# install.packages("remotes")
remotes::install_github("Abdoul-Faisal-Ouedraogo/ldapkg", dependencies = TRUE)
```

`dependencies = TRUE` also installs the packages used by the Shiny app (`shiny`,
`DT`, and optionally `readxl`, `data.table`). The core package itself only
depends on `R6` and base R packages. If the online installation fails, install
the archive shipped with the project:

```r
install.packages("ldapkg_0.1.0.tar.gz", repos = NULL, type = "source")
```

## Quick start

```r
library(ldapkg)

X <- iris[, 1:4]
y <- iris$Species

model <- LDAClassifier$new()
model$fit(X, y)

model                          # short description
summary(model)                 # detailed report
model$predict(X[c(1, 51, 101), ])
model$predict_proba(X[c(1, 51, 101), ])
```

See the **[tutorial](tutorial/tutorial.md)** for a complete walk-through
(output description, categorical predictors, variable selection,
cross-validation, plots and the Shiny application) and `?LDAClassifier` for
the reference documentation.

## Shiny application

```r
ldapkg::run_app()
```

Load a csv / tsv / txt / xlsx file (or an example dataset), pick the target,
the explanatory variables and the illustrative variables, choose the options
(priors, variable selection, hold-out sample, cross-validation), fit, explore
the results, and deploy the model on a single new individual or on a whole file
of new individuals (downloadable predictions).

## Example data

`ldapkg_example()` lists the datasets stored in `inst/extdata` (tab-separated):
`wine`, `breast_cancer` (UCI data) and `customers` (synthetic, mixed numeric /
categorical predictors with a few missing values). `ldapkg_example("wine", path = TRUE)`
returns the file path, handy to try the upload in the Shiny application.

## Repository layout

```
R/                    LDAClassifier.R (R6 class), core.R (computations), selection.R,
                      preprocess.R (encoding), methods.R (S3), examples.R, run_app.R
inst/shiny/ldaapp/    Shiny application
inst/extdata/         example datasets
man/                  help files (generated by roxygen2)
tests/testthat/       unit tests (comparison with MASS::lda and stats::manova)
tutorial/             reproducible tutorial (Rmd + rendered md)
report/               French report source and compiled PDF
data-raw/             provenance of the example data
```

The French project report is available as
[`report/report.pdf`](report/report.pdf), with its LaTeX source in
[`report/report.tex`](report/report.tex).
